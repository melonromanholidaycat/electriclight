Flash electriclight

Installs the firmware onto an ESP32-S3 over USB. Nothing to download and nothing to install on this computer — it all happens in this page.

build unknown

This browser cannot flash.

Flashing needs the Web Serial API, which today means Chrome, Edge or Opera on Windows, macOS or Linux. Safari and Firefox do not have it, and no browser on iOS or iPadOS does — iOS does not give apps access to a USB serial port at all.

Open this page in Chrome on a desktop or laptop.

ESP32-S3, 4 MB

The boards in hand: ESP32-S3FH4R2, the three-pack Super Minis. Use this one.

Different board? (16 MB modules)

Only for a module with 16 MB of flash. Installing this on a 4 MB board will not damage it, but it will not boot — reflash with the 4 MB build above to recover.

What to do

  1. Hold the BOOT button down while you plug the USB-C cable in, then let go. On a board that has never run this firmware that is the normal way in, not a rescue: the ESP32-S3 has no separate USB chip, so whether it appears as a port at all depends on what the factory firmware does. Holding BOOT starts the ROM loader, which always appears.
  2. Use a cable that carries data. A charge-only cable powers the board and never appears as a port, which looks exactly like a broken board. If nothing new shows up, suspect the cable first.
  3. Click Install and pick the port. It will not be the only one listed — this computer's own serial ports appear too. The board is the one that looks like USB JTAG/serial debug unit or USB Serial Device. Anything described as a PCI or built-in serial port is not it. Picking the wrong one is harmless: flashing stops at the point where the chip fails to answer, before anything is written.
  4. Choose Erase device on a board that has never run this firmware. It clears whatever the factory left behind. On a board already in use, do not erase: it would also wipe the stored WiFi credentials and effects. A plain install keeps them.
  5. Wait. About a minute.
  6. Press RESET when it finishes. The board is still sitting in the ROM loader from step 1 — it will say waiting for download in the log and do nothing else. One press of RESET, with BOOT not held, starts the firmware you just installed.
  7. If it offers to set up WiFi over the cable and then says the device does not support it, that is expected. This firmware is configured from its own page instead.
  8. Do all three boards while the computer is here. Spares are only spares if they are ready to swap in.

While you are here: read the boot log.

Click the button again on a flashed board and choose Logs & Console. This is the only moment in the project when serial output exists at all — the finished instrument has no console, which is why so much of the firmware is built to report over WiFi instead. Worth a look before the computer goes back.

Before you hand the computer back

Check the board actually came up, using your phone — while a second flash is still cheap.

  1. On the phone, join the WiFi network electriclight, password electric-light.
  2. Open 192.168.4.1. The control page should load, with a device badge instead of simulator.

The phone is the only check that means anything today. The board has an addressable LED on GPIO48, but no firmware yet drives it — a dark board is not a failed flash.

In the log you are looking for fallback access point "electriclight" is up and main: ready. On the first boot of a new build it also runs the effect evaluator against the golden vectors, which takes about twenty seconds and prints 16/16 cases, 104 frames, all match.

The password is in the repository on purpose. It is a deterrent, not a secret: being locked out of a closed guitar is much worse than a stranger in radio range changing the lights.

If the board is not offered as a port

A board whose firmware is broken can still be flashed, but it may need to be put into download mode by hand. The board has both buttons, either side of the USB-C socket: hold BOOT, press and release RESET, then release BOOT, and click Install again. That path works no matter what is on the board, which is why a bad image is never permanent.
